# Indoor Delivery Robot — Phase 1 Web UI

Frontend prototype for the Indoor Autonomous Delivery Robot project.

## Stack
- Next.js
- React
- TypeScript
- Tailwind CSS
- Mock data only

## Pages
- `/` Dashboard
- `/delivery` Create Delivery
- `/tasks` Task Queue
- `/stations` Station Management
- `/robots` Robot Status

## Run
1. Install Node.js LTS.
2. Open a terminal in this folder.
3. Run `npm install`
4. Run `npm run dev`
5. Open `http://localhost:3000`

## Phase 1 scope
No FastAPI, PostgreSQL, MQTT, ROS2, or authentication yet. The goal is to validate the UI and delivery workflow first.
