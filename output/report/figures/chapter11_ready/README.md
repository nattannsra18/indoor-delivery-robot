# ชุดรูปประกอบบทที่ 11

โฟลเดอร์นี้จัดรูปตามลำดับที่ใช้ในรายงานถึงหัวข้อ 11.3

## รูปที่ 11.1 ตัวอย่างส่วนติดต่อของเว็บแอปพลิเคชันตามประเภทผู้ใช้งาน

- `(ก)` Dashboard ของผู้ดูแลระบบ
- `(ข)` Dashboard ของผู้ใช้ทั่วไป

## รูปที่ 11.2 ผลการทดสอบการสร้างและยกเลิกภารกิจ

- `(ก)` TASK-305 หลังสร้างและอยู่ในสถานะ Queued
- `(ข)` TASK-303 ขณะอยู่ในสถานะ Going to pickup และมีคำสั่งยกเลิก
- `(ค)` ประวัติเหตุการณ์หลังยกเลิก TASK-303

หมายเหตุ: การสร้างคิวและการยกเลิกใช้หลักฐานจากคนละภารกิจ

## รูปที่ 11.3 การแสดงรายการและประวัติเหตุการณ์ของภารกิจ

- `(ก)` รายการภารกิจและสถานะที่บันทึกในระบบ
- `(ข)` ประวัติเหตุการณ์ของ TASK-288

## รูปที่ 11.4 ผลการสร้าง บันทึก และนำแผนที่กลับมาใช้ระบุตำแหน่ง

- `(ก)` การสร้างแผนที่ด้วย SLAM
- `(ข)` การตรวจสอบและกำหนดชื่อ Map-Test-01
- `(ค)` Map-Test-01 หลังบันทึกและกำหนดเป็นแผนที่ที่ใช้งาน
- `(ง)` ผลการกำหนดตำแหน่งเริ่มต้นและสถานะ Localized

วิดีโอการสร้างแผนที่: https://www.youtube.com/watch?v=5Lu37r9D3EI

## รูปที่ 11.5 ตัวอย่างลำดับการทำงานของ TASK-288

- `(ก)` เส้นทางของภารกิจจากสถานีต้นทางไปยังสถานีปลายทาง
- `(ข)` หุ่นยนต์ถึงสถานีต้นทางและรอการยืนยันโหลด
- `(ค)` หุ่นยนต์อยู่ระหว่างเดินทางไปยังสถานีปลายทาง
- `(ง)` ภารกิจเสร็จสมบูรณ์

ประวัติเหตุการณ์ฉบับเต็มใช้รูปที่ 11.3 (ข) จึงไม่ต้องใส่ภาพเดิมซ้ำในหัวข้อ 11.3
