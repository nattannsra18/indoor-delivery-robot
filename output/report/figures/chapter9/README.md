# ชุดแผนภาพสำหรับบทที่ 9

ไฟล์แต่ละรูปมีทั้ง SVG สำหรับแก้ไขหรือขยายโดยไม่สูญเสียความคมชัด และ PNG ขนาด 2400 × 1350 พิกเซลสำหรับนำไปวางใน Microsoft Word

1. `01_system_architecture`  
   คำบรรยายที่แนะนำ: **สถาปัตยกรรมระบบหุ่นยนต์เคลื่อนที่อัตโนมัติควบคุมผ่านเว็บ**  
   ตำแหน่งที่แนะนำ: หัวข้อสถาปัตยกรรมเว็บและ Robot Agent

2. `02_robot_sensor_layout`  
   คำบรรยายที่แนะนำ: **ตำแหน่งอุปกรณ์และเซนเซอร์บนหุ่นยนต์ต้นแบบ**  
   ตำแหน่งที่แนะนำ: หัวข้อส่วนประกอบฮาร์ดแวร์  
   หมายเหตุ: เป็นผังตำแหน่งเชิงหน้าที่ ไม่ใช่แบบประกอบตามมาตราส่วน ควรวัดตำแหน่งกล้องและเพลาล้อก่อนนำระยะไปใช้เป็นข้อมูลแบบผลิต

3. `03_motor_control_loop`  
   คำบรรยายที่แนะนำ: **วงรอบควบคุมฐานขับเคลื่อนและข้อมูลย้อนกลับ**  
   ตำแหน่งที่แนะนำ: หัวข้อการควบคุมมอเตอร์และการป้อนกลับ

4. `04_slam_amcl_nav2_process`  
   คำบรรยายที่แนะนำ: **กระบวนการสร้างแผนที่ ระบุตำแหน่ง และนำทางอัตโนมัติ**  
   ตำแหน่งที่แนะนำ: หัวข้อ SLAM, AMCL และ Nav2

5. `05_mission_state_diagram`  
   คำบรรยายที่แนะนำ: **แผนภาพสถานะภารกิจรับและส่งสิ่งของ**  
   ตำแหน่งที่แนะนำ: หัวข้อหลักการจัดการภารกิจ

สำหรับเอกสาร Word ให้ใช้ PNG หากต้องการความเข้ากันได้สูงสุด หรือใช้ SVG เมื่อ Word รุ่นที่ใช้งานรองรับและต้องการความคมชัดสูงสุด
